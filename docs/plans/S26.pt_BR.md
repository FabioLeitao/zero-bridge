# S26 — Cartões de sugestão, chip de modo e polimento de teclado

Track D, repo `zero-bridge` → `bridge/web/`.

## Escopo

- Cartões de sugestão de estado vazio (ex.: "Explorar o código", "Revisar o projeto") que apenas preenchem o compositor; nunca enviam sozinhos.
- Um chip de status que indica o modo atual em palavras ("Escreve pede aprovação" para `ask`, etc.), tirado dos nomes e descrições dos modos do agente, apenas texto.
- Teclado: Enter envia, Shift+Enter nova linha, foco retorna ao compositor após um turno.

## Aceitação

- 320 px sem overflow.
- Regiões ARIA live para o chip.
- Descrição de modo hostil como texto.

## Dependências

S6b (gerenciamento de workspace, lista de sessões), S19 (gate de capacidade, modos do agente).
