# S26 — Suggestion cards, mode chip, keyboard polish

Track D, repo `zero-bridge` → `bridge/web/`.

## Scope

- Empty-state suggestion cards (e.g., "Explore the codebase", "Review the project") that only fill the composer; they never send by themselves.
- A status chip that states the current mode in words ("Writes ask for approval" for `ask`, etc.), taken from the agent's own mode names and descriptions, text only.
- Keyboard: Enter sends, Shift+Enter newline, focus returns to the composer after a turn.

## Acceptance

- 320 px without overflow.
- ARIA live regions for the chip.
- Hostile mode description as text.

## Dependencies

S6b (workspace management, session list), S19 (capability gate, modes from agent).
