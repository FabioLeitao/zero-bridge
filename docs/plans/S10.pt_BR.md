# S10 — Ferramenta de plugin a2a_list

Track B3, repo `zero-bridge` → `plugin/a2a/`.

## Escopo

- Ferramenta de plugin `a2a_list` para listar peers A2A configurados.
- Lê `plugin/a2a/peers.json` e envia a lista de peers como JSON.
- Lê stdin vazio `{}`, envia array JSON de peers com campos name, url, description, allowed.
- v1 envia lista de um único peer somente leitura.

## Aceitação

- `zero tools list` contém `a2a_list`.
- Tool stdin `{}` → saída **0**; stdout array JSON com tamanho igual às entradas de `peers.json`.
- `zero plugins` diagnósticos: nenhum erro `kind: schema` para este plugin.

## Dependências

S9 (ferramenta de plugin a2a_call).
