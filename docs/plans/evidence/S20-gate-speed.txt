Fifteen slowest internal/server tests under -race (command 2). The shared cause is the test helper: it calls http.Server.Shutdown with a 5s context. Shutdown polls until every connection is idle. A connection left in StateNew is treated as idle only after 5s (net/http). Under -race that wait shows up as about 1.0s on almost every test that boots a server; sometimes the whole 5s context is consumed. A package test that does not boot a server stays under 0.1s in the same run, so the second is not the race runtime (that cost is paid once per process). CPU for the package is about 4s either way.
