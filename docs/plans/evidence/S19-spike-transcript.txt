hermes acp — nao executado

The launcher on PATH is a shell script that execs the binary inside the Hermes checkout. Every launch runs _settle_interrupted_update() before the command. That function can restore an interrupted update by moving files in the checkout (restore_interrupted_pull on the checkout root). An isolated HOME does not cover that tree or the install's Hermes home. The process was not started.

That lookup is not proven to stay offline and keyless, so the profile was not started.
