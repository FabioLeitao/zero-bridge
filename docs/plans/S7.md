# S7 — A2A ingress (Agent Card + message/send)

Track C5, repo `zero-bridge` → `bridge/a2a/`.

## Scope

- Agent Card at `/.well-known/agent-card.json` — returns 200 with a `name` field.
- JSON-RPC `message/send` on loopback with a valid payload → 200 and a task id. The bridge issues `session/prompt` on a zero-cost model.
- `--listen 0.0.0.0:8765` exits 2.
- Through the S14 proxy, a missing credential is the same 401 as S14.
- A POST body over the configured maximum → 413.
- Agent Card and `message/send` only — no full task surface (no `tasks/get`, `tasks/cancel`, etc.).
- The bridge never listens outside loopback; external access goes through S14 reverse proxy with token. TLS ends at the proxy.

## Acceptance

- `curl -sf http://127.0.0.1:8765/.well-known/agent-card.json` → 200, JSON with a `name` field.
- JSON-RPC `message/send` on loopback with a valid payload → 200 and a task id. The bridge issues `session/prompt` on a zero-cost model.
- `--listen 0.0.0.0:8765` exits 2.
- Through the proxy, a missing credential is the same 401 as S14.
- A POST body over the configured maximum → 413.
- Agent Card and `message/send` only — no full task surface.

## Dependencies

- S14 (proxy-ready, token auth, loopback enforcement)
- S19 (capability gate, ACP client)
