# S7 — Entrada A2A (Agent Card + message/send)

Track C5, repo `zero-bridge` → `bridge/a2a/`.

## Escopo

- Agent Card em `/.well-known/agent-card.json` — retorna 200 com campo `name`.
- JSON-RPC `message/send` em loopback com payload válido → 200 e task id. O bridge emite `session/prompt` em modelo zero-custo.
- `--listen 0.0.0.0:8765` sai com código 2.
- Através do proxy S14, credencial ausente resulta no mesmo 401 do S14.
- Body POST acima do limite configurado → 413.
- Agent Card e `message/send` apenas — sem superfície completa de tasks (sem `tasks/get`, `tasks/cancel`, etc.).
- O bridge nunca escuta fora de loopback; acesso externo vai pelo proxy reverso S14 com token. TLS termina no proxy.

## Aceitação

- `curl -sf http://127.0.0.1:8765/.well-known/agent-card.json` → 200, JSON com campo `name`.
- JSON-RPC `message/send` em loopback com payload válido → 200 e task id. O bridge emite `session/prompt` em modelo zero-custo.
- `--listen 0.0.0.0:8765` sai com código 2.
- Através do proxy, credencial ausente é o mesmo 401 do S14.
- Body POST acima do limite configurado → 413.
- Agent Card e `message/send` apenas — sem superfície completa de tasks.

## Dependências

- S14 (proxy-ready, token auth, loopback enforcement)
- S19 (gate de capacidade, ACP client)
