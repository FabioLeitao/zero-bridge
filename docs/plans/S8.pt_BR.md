# S8 — Ferramenta de plugin a2a_discover

Track B1, repo `zero-bridge` → `plugin/a2a/`.

## Escopo

- Estrutura do plugin: `plugin/a2a/plugin.json`, `plugin/a2a/tools/a2a_discover/` (Go main).
- A ferramenta lê um Agent Card de um peer A2A, allowlist de hosts aplicada antes de qualquer dial (host não permitido sai com código não-zero sem fazer chamada de rede).
- Testado com peer httptest.

## Aceitação

- Com plugin copiado para um projeto de teste `.zero/plugins/zero-bridge-a2a/`: saída de `zero tools list` contém `a2a_discover`.
- `zero plugins validate` (ou diagnósticos do projeto) relata nenhum erro de schema para este plugin.
- `go test ./plugin/a2a/tools/a2a_discover/ -count=1`: peer httptest em `127.0.0.1`; stdin da ferramenta `{"url":"http://127.0.0.1:<port>"}` → saída **0**; stdout JSON inclui campos de capacidade do Agent Card mock.
- Mesmo teste: host URL `http://evil.example/` quando allowlist só contém `127.0.0.1` → saída **não-zero**, stderr menciona host não permitido (sem chamada de rede).

## Dependências

- S7 (entrada A2A, endpoint Agent Card)
