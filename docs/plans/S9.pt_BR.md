Track B2, repo `zero-bridge` → `plugin/a2a/`.

## Escopo

- Ferramenta de plugin `a2a_call` para chamar um peer A2A com uma mensagem.
- Manifesto `permission: prompt`; peer mock com httptest.
- Peer 500 sai com código não-zero sem substrings de token no stderr.
