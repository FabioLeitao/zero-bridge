# S10 — a2a_list plugin tool

Track B3, repo `zero-bridge` → `plugin/a2a/`.

## Scope

- Plugin tool `a2a_list` for listing configured A2A peers.
- Reads `plugin/a2a/peers.json` and outputs the list of peers as JSON.
- Reads empty stdin `{}`, outputs JSON array of peers with name, url, description, allowed fields.
- v1 ships a single-peer read-only list.

## Acceptance

- `zero tools list` contains `a2a_list`.
- Tool stdin `{}` → exit **0**; stdout JSON array length matches `peers.json` entries.
- `zero plugins` diagnostics: no `kind: schema` errors for this plugin.

## Dependencies

S9 (a2a_call plugin tool).
