# S23b — Shell desktop: bandeja, notificações de permissão, seletor de pasta

Track D, repo `FabioLeitao/zero-bridge-desktop`.

## Escopo

- Ícone na bandeja com mostrar/esconder e sair; estado da janela restaurado.
- Notificação nativa quando o bridge reporta uma permissão pendente enquanto a janela está escondida. Apenas texto: o título da ferramenta já mostrado no card de permissão, nada da saída do agente além disso. Clicar foca a janela naquele card.
- Seletor de pasta para o workspace de uma nova sessão, validado contra o `--workspace-root` do bridge; pasta solta (drag & drop) aceita da mesma forma.
- Início opcional no login; trava de instância única; deep link `zero-bridge://` validado e não habilitado até haver uso para ele.

## Aceitação

- Título de ferramenta hostil mostrado como texto na notificação; o seletor recusa caminho fora do workspace root; segundo lançamento foca a primeira janela.

## Dependências

S23a (shell pai deste issue), #2 (S6b).

## Status

- Implementado em `FabioLeitao/zero-bridge-desktop` branch main.
- TrayController, PermissionNotifier, FolderPicker adicionados com testes unitários.
- Canais IPC expostos via preload: `zb:permission-request`, `zb:pick-workspace`, `zb:folder-drop`, `zb:fetch-workspace-roots`, `zb:permission-focus`.
- Processo principal conecta tray, notifier, folder picker à janela Electron.
- Trava de instância única via `app.requestSingleInstanceLock()`.
- Folder picker validado contra `workspaceRoots` do bridge `/v1/capabilities`.
