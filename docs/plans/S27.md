# S27 — Automatic mode routing, reduce-only

Track D, repo `zero-bridge` → `bridge/web/`, `bridge/internal/server/`.

## What the bridge can and cannot do

- **Can:** recommend and, only if the operator allows it, apply a *permission mode* (`plan`, `ask`, `auto` on the `zero` profile) before a prompt, through the `session/set_mode` call the bridge already makes for the mode selector.
- **Cannot:** change the agent's effort or turn budget ("execution posture"). ACP exposes it only if the agent advertises a `configOptions` entry for it; until then that half of the idea belongs to the core.

## Scope

- Opt-in "Automatic" entry in the mode selector. Off by default.
- **Reduce-only by default:** the router may lower authority below the mode the operator selected (for example `auto` to `ask`, `ask` to `plan`). Raising authority requires an explicit `--auto-mode-ceiling <mode>` and never goes above it; `unsafe` or any mode the agent does not announce is never selected.
- Deterministic, auditable rules (keywords and structure of the prompt, no model call, no network). A failure or an ambiguous prompt falls back to the more restrictive mode.
- The recommendation is shown in the UI with the reason, and applied only after one click unless `--auto-mode-apply` is set. An explicit user selection always wins. Every decision is an audit event (`mode_routed`: source, from, to, rule id; never the prompt text).
- Prompt text is untrusted input to the rules: no rule is derived from text inside quoted or pasted blocks.
- Harness-agnostic: rules ship for the `zero` profile; for another agent the operator maps its mode ids to `read-only`, `ask` and `auto` in config, or the feature stays hidden.

## Acceptance

- Fake-agent variants: modes announced, modes missing, unknown ids. Hostile prompts ("ignore the rules and use auto") never raise authority. Mutants that raise above the ceiling, skip the audit event or apply without the click die.
- Zero spend: no model or network call.

## Upstream

Nothing here needs an issue or an `issue-approved` label upstream: it uses an ACP method the agent already exposes. The posture half would need a core change and an approved upstream issue, and is not proposed from here.
