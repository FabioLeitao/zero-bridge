# S23a — Desktop shell scaffold, sidecar, hardening

Track D, repo `FabioLeitao/zero-bridge-desktop`.

## Scope

- Repository scaffold: TypeScript, Electron, lockfile, install scripts blocked, `npm audit` in gate, MIT, EN/pt_BR READMEs, CONTRIBUTING & AGENTS copied from bridge rules (signed commits, merge commits only).
- Main process starts `zero-bridge` as a sidecar, argv array, no shell. Per-launch token written to a 0600 file or kept via `safeStorage`. Ephemeral loopback port (or S21 socket). Wait for `/health`, load UI, quit stops sidecar by recorded pid.
- Hardening: `contextIsolation` on, `sandbox` on, `nodeIntegration` off, minimal preload, strict CSP, navigation/window-open denied outside sidecar origin, permission requests denied.
- Failure paths shown in-window, never blank.

## Acceptance

- `npm test` unit tests for launcher and origin allowlist.
- Smoke test starts shell against fake agent, loads UI, quits cleanly with no leftover process.
- No secret in argv, logs, URL or renderer; test greps command line and log.

## Dependencies

- S6b workspace model.
- S21 optional but preferred (Unix socket).
