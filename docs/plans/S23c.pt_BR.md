# S23c — Shell desktop: testes e2e e pacotes Linux

Track D, repo `FabioLeitao/zero-bridge-desktop`.

## Escopo

- Testes end-to-end com suporte Electron do Playwright: lançamento, chat contra o agente fake, card de permissão, caminho de notificação, sair.
- Pacotes Linux primeiro: AppImage e `.deb`, construídos de forma reproduzível no gate local sem CI (`npm run dist`); checksums e SBOM ao lado dos artefatos.
