# S24 — Model picker from the agent's configOptions

Track D, repo `zero-bridge` → `bridge/web/`.

## Scope

The agent declares `configOptions` on `session/new` (S19 already reads and keeps them). When an option has `type` select with a non-empty `options` list, the UI offers a selector and sends the agent's own `session/set_config_option` (or the method the agent advertises).

Hidden when the agent offers no list; today `zero acp` returns `options: null` for `model`, so this depends on upstream.

Values and names come from the agent and are untrusted: text only, and validated against the offered list before sending, as for modes.

Zero-spend rule: the bridge never selects a model by itself.

## Acceptance

- Fake-agent variant with and without options.
- Hostile option name as text.
- Value outside the list is `400` and never sent.
- Mutant that skips validation dies.

## Dependencies

S19 (capability gate, configOptions), S6b (workspace management).
