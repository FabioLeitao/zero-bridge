# S18 — Imagem de container: loopback em namespace compartilhado, non-root, read-only, zero e token montados

Track C, repo `zero-bridge`.

## Design

- **Rede:** o bridge e o proxy reverso compartilham um namespace de rede (compose `network_mode: "service:<proxy>"`, ou pod Podman / quadlet `.pod`). O bridge mantém `--listen 127.0.0.1:<porta>` dentro desse namespace e apenas a porta do proxy é publicada. Nenhum bind `0.0.0.0`, nenhuma flag especial "container".
- **Imagem:** build multi-stage, binário estático (`CGO_ENABLED=0`), base mínima, usuário non-root, rootfs read-only, `cap_drop: [ALL]`, `no-new-privileges`, tmpfs `/tmp`.
- **Binário `zero`:** não embutido. O build do fork patchado (`FabioLeitao/zero`) é montado read-only e passado via `--zero-bin`; upstream stock não é suportado até os fixes ACP chegarem.
- **Segredos:** token como arquivo `0600` dono do usuário do container (secret montado) via `--token-file`. A checagem "sem bits group/other" do loader permanece; um secret montado world-readable deve falhar com mensagem clara, não ser aceito silenciosamente. Nunca em argv ou camadas da imagem.
- **Workspace:** apenas diretórios bind-montados existem para o agente, que é uma segunda camada de confinamento sobre `--workspace-root` (S6b). Documentar que ferramentas precisando de toolchain (git, go, node) exigem imagem maior ou mounts extras.
- **Estado:** volume nomeado para metadata S6b/S14b e audit file (`--state-dir`, `--audit-log`).
- **Health:** `HEALTHCHECK` contra o `GET /health` mínimo.
- **Telemetria (S16):** endpoint OTLP pelo namespace compartilhado ou flag explícita non-loopback.
- **Runtimes:** Docker/Compose no host dev e Podman quadlets no outro nó; mesma imagem.

## Aceitação

- `docker build` reproduzível e a imagem roda como non-root com rootfs read-only.
- Exemplo Compose/quadlet: bridge + Caddy no mesmo namespace; `GET /health` 200 via proxy; login, prompt e SSE streaming funcionam (mesmos checks do transcript S14).
- Iniciar o container com `--listen` non-loopback ainda sai com código 2.
- Token montado com permissão group/other readable é recusado.
- Transcript de evidência com comandos mostrados primeiro; `make check` verde; digest da imagem registrado.
