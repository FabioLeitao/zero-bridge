# S23c — Desktop shell: e2e tests and Linux packages

Track D, repo `FabioLeitao/zero-bridge-desktop`.

## Scope

- End-to-end tests with Playwright's Electron support: launch, chat against the fake agent, permission card, notification path, quit.
- Linux packages first: AppImage and `.deb`, built reproducibly in CI-less local gate (`npm run dist`); checksums and an SBOM next to the artifacts.
- Docs: install, update by hand, how the token is created and where it lives, how to report a security issue.
- Windows and macOS are explicitly not in this issue: they need signing, notarization and real-OS test runs, and become separate issues when someone can test them.

## Acceptance

- `npm run check` and the e2e pass locally; the packaged app starts, chats against the fake agent and stops the sidecar when quitting.

## Dependencies

S23a, S23b.
