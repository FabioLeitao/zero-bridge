# S18 — Container image: loopback inside shared namespace, non-root, read-only, mounted zero and token

Track C, repo `zero-bridge`.

## Design

- **Network:** the bridge and the reverse proxy share one network namespace (compose `network_mode: "service:<proxy>"`, or a Podman pod / quadlet `.pod`). The bridge keeps `--listen 127.0.0.1:<port>` inside that namespace and only the proxy's port is published. No `0.0.0.0` bind, no special "container" flag.
- **Image:** multi-stage build, static binary (`CGO_ENABLED=0`), minimal base, non-root user, read-only root filesystem, `cap_drop: [ALL]`, `no-new-privileges`, tmpfs `/tmp`.
- **`zero` binary:** not baked in. The patched fork build (`FabioLeitao/zero`) is mounted read-only and passed with `--zero-bin`; stock upstream is not supported until the ACP fixes land.
- **Secrets:** token as a `0600` file owned by the container user (mounted secret) via `--token-file`. The loader's "no group/other bits" check stays; a world-readable default secret mount must fail with a clear message, not be silently accepted. Never in argv or image layers.
- **Workspace:** only bind-mounted directories exist for the agent, which is a second confinement layer on top of `--workspace-root` (S6b). Document that tools needing a toolchain (git, go, node) require a fatter image or extra mounts.
- **State:** a named volume for the S6b/S14b metadata and audit file (`--state-dir`, `--audit-log`).
- **Health:** `HEALTHCHECK` against the minimal `GET /health`.
- **Telemetry (S16):** OTLP endpoint through the shared namespace or an explicit non-loopback allow flag.
- **Runtimes:** Docker/Compose on the dev host and Podman quadlets on the other node; same image.

## Acceptance

- `docker build` is reproducible and the image runs as non-root with a read-only rootfs.
- Compose/quadlet example: bridge + Caddy in one namespace; `GET /health` 200 through the proxy; login, prompt and SSE streaming work (same checks as the S14 transcript).
- Starting the container with a non-loopback `--listen` still exits 2.
- A token mounted with group/other readable mode is refused.
- Evidence transcript with commands shown first; `make check` green; image digest recorded.

## Order

After S17 and S14b, ideally after S16 so the image ships with the telemetry flags: S14 → S17 → S14b → S16 → **S18** → S6b → S7.
